# Anna Astra — «Погружение» ✶

Люксовый сайт астролога Анны: астрология · таро · руны.

## Как работает hero — три режима (авто-выбор)

| Приоритет | Файл в `assets/` | Что происходит |
|---|---|---|
| 1 | `hero.mp4` | **Видео-режим**: скролл масштабирует видео к шару (точка 50%/46%), космос (`cosmos.mp4`) раскрывается круговой маской из центра шара |
| 2 | `hero.jpg` или `hero.png` | **«Живая фотография»**: фото сцены + процедурные слои анимации (см. ниже) |
| 3 | ничего | **Резервная 3D-сцена** (three.js) |

Космос после пролёта: `cosmos.mp4` (видео) → `cosmos.jpg`/`cosmos.png` (фото) → процедурный шейдер.
Загрузка: GitHub → Add file → Upload files → папка `assets` → Commit. Код менять не нужно.

## «Живая фотография» — что анимируется поверх статичного кадра

Если загружены `hero.jpg|png` и `cosmos.jpg|png`:

- **Шар**: туманность внутри дышит и медленно вращается (4 рукава + золотое ядро), 46 звёзд мерцают внутри круга шара
- **Свеча**: тёплое свечение пульсирует (два синуса, имитация живого пламени)
- **Туман**: три полупрозрачных облака медленно дрейфуют над столом
- **Пылинки**: 14 частиц дрейфуют вверх в луче света
- **Скролл**: кадр наезжает на шар (origin = центр шара), затем космос раскрывается круговой маской из центра шара и остаётся фоном
- **Космос-фон**: Ken Burns (28 с, плавный зум-дрейф) + 110 мерцающих звёзд

### Подгонка под кадр

Точка шара задана в начале `js/living-scene.js`:
```js
var BALL = { x: 0.503, y: 0.345, r: 0.26 }; // доли кадра, r — доля высоты
var CANDLE = { x: 0.025, y: 0.21 };
```
Если маска/наезд чуть смещены — поменяйте цифры (x — доля ширины, y и r — доли высоты).

# ПРОМПТ-ПАКЕТ (если понадобится генерация видео)

## КРИТИЧЕСКИЕ ПРАВИЛА

1. **Камера полностью статична** — весь «наезд» делает сайт.
2. **Шар — точно в центре**: 50% ширины, ~46% высоты (для видео-режима), диаметр ~22% высоты кадра.
3. **Идеальный луп**: 8–10 секунд, первый кадр = последний.

## hero.mp4 (text-to-video)
```
Статичный кадр со штатива, камера полностью неподвижна, без наезда, панорамы и тряски.
Ракурс: уровень камеры чуть выше поверхности стола, объектив 35 мм, малая глубина резкости.
Кромешно тёмная комната в викторианском стиле. В центре кадра (50% ширины, 46% высоты) —
большой прозрачный стеклянный шар для гаданий диаметром 22% высоты кадра на тёмно-золотой
подставке в центре антикварного деревянного стола; внутри шара слабо светится
фиолетово-золотая туманность со звёздами. Слева две карты таро рубашкой вверх с золотым
тиснением, справа карта с золотым солнцем прислонена к стопке, на переднем плане пять серых
камней с рунами. Верхняя четверть кадра — чистая темнота. Анимация медленная: туман ползёт
по столу справа налево ~2 см/с; пламя свечи слева мерцает ±10%; пылинки дрейфуют в луче;
туманность в шаре вращается — оборот за минуту; по стеклу скользит отражение.
Свет: тёплая свеча слева, фиолетовый контровой справа, глубокие тени. Палитра: индиго,
уголь, золото. Фотореалистичный CGI-рендер 8k. Без людей, текста, движения камеры.
Бесшовный цикл 10 секунд.
```
## img2video (надёжнее)
Статичный кадр по промпту из версии ниже → оживление:
```
Оживи сцену деликатно: туман медленно ползёт по столу справа налево, пламя свечи мягко
мерцает, пылинки дрейфуют, туманность в шаре вращается и мерцает, по стеклу скользит

```
## cosmos.mp4
```
Почти незаметное медленное приближение 3% за 10 секунд через тёмную фиолетово-золотую
туманность, редкие мерцающие звёзды, очень темно, низкий контраст, без планет, текста
и резких движений. Бесшовный цикл 10 секунд.
```

## Техтребования

- `hero.mp4`: 1920×1080, 24–30 fps, H.264 без звука, 8–10 с, луп, ≤10 МБ
- `cosmos.mp4`: 1920×1080, 10 с, луп, H.264 без звука, ≤8 МБ
- Фото: 1920×1080+, JPEG/PNG, до ~3 МБ
